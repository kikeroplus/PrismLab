# PrismLab 仕様

PromptWordCrafter・ImageMimicArt・J-Rate の「作る」部分をまとめる生成アプリです。企画の経緯と画面の見本は企画書 (claude.ai の PrismLab 企画) にあります。

- 生成の決まりは J-Rate の `docs\generation-standard.md` に合わせる。生成・読み取り・盛る・差し込みは `..\GenCommon\gencommon` をそのまま使う。
- 見る・評価する・整理するのは J-Rate。PrismLab とのやりとりは、出力フォルダとファイルの★ (System.Rating) だけ。
- 画面は「量産ライン」と「物語」の 2 つ。T2I / I2I / I2V はモードとして選ばず、ワークフローと元画像から自動で決まる。

## 1. 機能を足すときの基準

新しい機能は、作る前に次のどこに入るかを決める。どこにも入らないものは作らない (ComfyUI のワークフロー側でできないか先に考える)。

| 入れる先 | 中身 |
|---|---|
| 量産ラインの段 | フォルダ全体に同じことをする。人の手を待たない |
| 物語のシーン | 1 つを見て直して選ぶ |
| GenCommon | 両方で使う (1 か所直せば両方に効く) |
| J-Rate | 見る・比べる・評価する・整理する |

## 2. 見た目

- 暗い配色 (ImageMimicArt と同じ。ui-standard 14 章)。
- **ワークフローの種類の色は、今の色分けを引き継ぐ** (`gencommon.set_cards.KIND_COLORS`): T2I 青・I2I 緑・I2I CN 紫・T2V 橙・I2V 赤紫。札の文字も同じ (`T2I` / `I2I` / `I2I CN` / `T2V` / `I2V`)。Depth などで構図を写す I2I は「I2I CN」(ControlNet を使う I2I) として紫になる。見分け方も今と同じ (`comfy.workflow_kind` と `comfy.uses_controlnet`)。
- LLM を使う段 (読み取り・盛る) は、図の画面の LM Studio の薄紫 (`#a9a2ed`) で縁取る。
- 状態は文字より絵で見せる: 段ごとに出来たもののサムネール、進み具合の棒。失敗したものは赤い枠。
- 設定は段の中に閉じる: 段をクリックしたときだけ、その段の設定を開く。

## 3. 量産ライン

### レシピ

- 入口 (フォルダと★の絞り込み) と、左から右へ並べた段でできている。よく使うつなぎ方をレシピとして保存し、上の札で切り替える。
- 段は 3 種類: **読み取り** (読み取りプリセット・読み取り済みでも読み直す)、**盛る** (エンハンサー)、**生成** (ワークフロー・長さ・ベースプロンプトを付けるか)。
- 生成の段は何段でもつなげる。生成の段で出来たファイルが、次の段の元になる (「実写 → I2I CN → 読み取り → 盛る → I2V」)。出来たファイルが複数 (画像が何枚も出る I2I) のときは、次の段には 1 つ目を渡す。
- 生成の段を通ったら、プロンプトは空に戻す (新しいファイルには新しい説明が要るので)。プロンプトが空のまま生成の段に来たら、ワークフローに書かれたプロンプトのまま送る。
- 中身は値で覚える (ワークフローはパス)。読み取りプリセットとエンハンサーは名前で覚える (generation-standard 2 章と同じ)。
- 初めて起動したときは「★から動画」「実写クローン」「クローン → 動画」の 3 つを入れておく (ワークフローは未設定)。
- 置き場所: `%APPDATA%\PrismLab\recipes.json`。

### 入口

- フォルダの直下の画像 (`.png .jpg .jpeg .jpe .webp .bmp`)。名前順 (自然順)。
- ★の絞り込み: なし / ★1 以上 〜 ★5。★はファイルの System.Rating (J-Rate と同じ: 1 / 25 / 50 / 75 / 99) を読む。
- 入口の札に、対象の枚数と先頭の 3 枚を出す。

### 出力

- 出力フォルダは、レシピで決めたフォルダ。空なら `(入口のフォルダ)\(レシピ名)`。
- 名前は `(元の名前)_(印).(拡張子)`。印は動画なら `video`、画像はワークフローの種類で `t2i` / `i2i` / `cn`。つないだ段では続けて付く (`photo_cn_video.mp4`)。同じ名前があれば ` (2)` を付ける (上書きしない)。
- 生成の記録は今のアプリと同じ形で `%APPDATA%\PrismLab\comfy_history.txt` に残す。
- 読み取った説明は、読み取ったファイルと同じ名前の `.txt` に書く (generation-standard 6 章)。

### 振り分け (台)

- ComfyUI を最大 3 台まで使う。台は登録してある接続先から選ぶ (「台の設定...」)。役割は決めず、空いた台に何でも回す。
- 1 台に同時に 2 件まで送る (generation-standard 6 章)。終わった台から次の 1 件を取る。
- ワークフローはどの台も同じものを使う (`\\RAVEN\SharBox\workflow\Common Workflow` にまとめる予定)。ワークフローが使うモデルは、どの台にも同じ名前で置く。
- 台に繋がらなくなったら、その台の分を待機に戻して、ほかの台に回す。繋がらない台は 30 秒ごとに確かめ、戻ったらまた回す。
- ある台で 3 件続けて失敗したら (台には繋がるのに)、その台を外して理由を出す。「台の設定...」を開き直すと戻る。
- 読み取り・盛る (LLM) は台とは別に 1 つずつ進め、生成より先に進めておく。

### 開始・一時停止・中止

- 「開始」で、入口の対象 1 枚につき 1 件を作る。始めたときのレシピ・読み取りプリセット・エンハンサー・ベースプロンプトの写しを持つ (途中で設定を変えても、始めたときの中身で続ける)。
- 「一時停止」: 新しく頼むのをやめる。頼み済みのものは最後まで受け取る。「再開」で続ける。
- 「中止」: 確かめてから、待機中のものを取り消し、実行中のものは ComfyUI に中断を送る。
- 失敗したものは「失敗したものをやり直す」で、失敗した段からやり直す。

### 続きから始める

- 終わっていない量産は、状態が変わるたびに `%APPDATA%\PrismLab\line_run.json` に書く (頼み済みのものは台と `prompt_id` も)。
- 量産中に閉じようとしたら「残して閉じる / 捨てて閉じる / やめる」を聞く。残して閉じたとき・PC が落ちたときは、次に起動したときに「続きから始める / 中断する」を聞く。
- 続きから始めると、頼み済みのものはその台で結果を待つ (その台がないか繋がらなければ、ほかの台で頼み直す)。読み取り・盛るが済んだ段はやり直さない。
- アプリは 2 重に起動しない (2 つ目は起動中のウィンドウを前に出して終わる)。

### 結果

- 下に、出来たものを新しい順にサムネールで並べる。失敗したものは赤い枠で、理由を指を置くと出す。ダブルクリックで関連付けアプリで開く。
- 「出力フォルダを開く」「J-Rate で開く」(出力フォルダを J-Rate に渡す)。
- すべて終わったとき、アプリが手前にいなければタスクバーの点滅で知らせる。

## 4. 物語 (段階 3)

- シーンを横に並べた絵コンテ。シーンの間のつなぎ方は「続き」(前のシーンで採用した動画の最後のコマを元画像にする) と「シーンチェンジ」(元画像を選び直す: 手元の画像 / T2I で作る / 前のシーンのコマ)。
- シーンごとにプロンプト (読み取り → 手直し → 差し込み → 盛る) と候補。候補から 1 つを採用して次へ。
- 「▶ 通して再生」で採用した動画を続けて再生する。書き出しは動画編集ソフトでやる。PrismLab は採用した動画を `01_名前.mp4` の番号順でフォルダに揃える。

## 5. 作る順番

1. 量産ライン: レシピ・入口・段・振り分け・続きから・結果 (この版)
2. 振り分けの仕上げと J-Rate への受け渡し (評価の引き継ぎ、差し込みの段、テキストを入口にする T2I)
3. 物語
4. 旧アプリから生成を外す

## 6. まだやっていないこと (この版)

- 差し込み (セリフ・アクション) の段
- テキストファイルを入口にする (T2I の量産)
- 元画像の評価を出来たファイルに引き継ぐ (generation-standard 6 章のオプション)
- 回数 (同じ元から何本も作る)
