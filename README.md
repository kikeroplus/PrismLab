# PrismLab

フォルダの画像から、読み取り → 盛る → ComfyUI の生成を、ステップをつないだ「量産ライン」で夜のあいだ回す PySide6 製のアプリです。ComfyUI は 3 台まで振り分けます。出来たものを見る・評価するのは J-Rate です。

```
入口 (フォルダ・★の絞り込み) → 読み取り → 盛る → 生成 (I2V など) → … → 出力フォルダ → J-Rate
```

決まりごとは [docs/spec.md](docs/spec.md) にあります。生成は J-Rate の `docs\generation-standard.md` に合わせ、生成・読み取り・盛るの部品は隣の `..\GenCommon\gencommon` を使います。

## セットアップと起動

```powershell
pip install -r requirements.txt
```

`run_app.bat` をダブルクリックするか、このフォルダで `python main.py` を実行します。すでに起動しているときは、起動中のウィンドウを手前に出します。

接続先・ワークフロー・ベースプロンプト・エンハンサー・読み取りプリセット・LLM の接続は、J-Rate・PromptWordCrafter・ImageMimicArt と共有します (`%APPDATA%\GenCommon\`)。

### EXE を作る

ImageMimicArt と同じく、PyInstaller で 1 つの EXE にします (隣の `..\GenCommon` も取り込みます)。

```powershell
python -m PyInstaller PrismLab.spec --noconfirm   # → dist\PrismLab.exe
```

- アイコンは `assets\icon.ico`。アプリのアイコン (`prismlab.main.make_icon`) を変えたら `python tools\make_ico.py` で作り直します。
- GenCommon を直したときも、EXE を作り直します (作った時点の GenCommon が中に入るため)。
- 1 ファイルの EXE なので、起動すると EXE のプロセスが 2 つ (起動役と本体) 見えます。

## 使い方 (量産ライン)

1. **台の設定...**: 量産で使う ComfyUI を 3 台まで選びます (登録してある接続先から)。
2. 上の札で**レシピ**を選びます。初めは「★から動画」「実写クローン」「クローン → 動画」があります。右クリックで名前を変える・複製・並べ替え・削除、「＋ レシピ」で足せます。
3. **入口**のステップをクリックしてフォルダを選び、★の絞り込みを決めます (J-Rate で付けた★を読みます)。★をこれから付けるときは、入口の「J-Rate で★を付ける」で J-Rate を開き、付け終わったら PrismLab に戻ります。戻ったときに★を読み直して、対象の枚数と★の内訳を描き直します。
   入口の上の **[テキスト]** に切り替えると、フォルダの .txt を 1 つずつ元の文にして T2I で量産します (最初の生成は T2I / T2V に)。**回数**はどの入口でも使え、同じ元を何回通すかを決めます。
   入口の上の **[1 枚]** に切り替えると、フォルダのかわりに 1 枚の画像から始めます (クリックかドラッグで選ぶ)。**回数**ぶん同じ画像を通すので、差し込み・盛るで 1 本ずつ違うものが出来ます。
4. **ステップ**をクリックして、そのステップの設定 (読み取りプリセット / エンハンサー / 足す文 / 差し込みのフォルダ / ワークフロー・長さ) を決めます。**追加テキスト**は入力した文を、**差し込み**はフォルダの .txt を 1 枚ごとに順に、プロンプトに足します。「盛る」より前に置くと一緒に盛り、あとに置くとそのまま付けます。「＋ ステップ」で末尾に足し、ステップのあいだの **→** (乗せると「＋」) を押すとそこに挿入します。右クリックで設定・種類を変える・左/右に挿入・複製・バイパス・並べ替え・削除ができます。ステップ右上の **↷** はバイパスのスイッチで、入れるとそのステップを飛ばします (外してもラインが成り立つステップにだけ出ます)。
5. 出力の行の **元の★を引き継ぐ** (既定はオン) で、元の★を出来たファイルに付けます (1 件が終わった時点の★。更新日時は変えません)。
6. 量産の前に試すときは **▶ 1 枚で試す**。入口のサムネールをクリックするか、画像を入口にドラッグして 1 枚を選びます (選ばなければ先頭)。出力は `出力フォルダ\試作` に入り、右の欄に読み取った文・盛った文が出ます。結果を選ぶと、ふだんの量産でもその元と文が見られます。
7. **▶ 開始**。出来たものは下の「結果」に新しい順に並びます。「J-Rate で開く」で出力フォルダを J-Rate に渡します。

- ステップの色は、今のワークフローの色分けと同じです (T2I 青・I2I 緑・I2I CN 紫・T2V 橙・I2V 赤紫)。LLM のステップ (読み取り・盛る) は薄紫です。
- 出力は `(入口のフォルダ)\(レシピ名)\(元の名前)_video.mp4` など (出力フォルダは変えられます)。つないだステップでは `photo_cn_video.mp4` のように続けて付きます。
- 台に繋がらなくなったら、残りはほかの台に回し、戻ったらまた回します。
- 閉じるときに「残して閉じる」を選ぶと、次に起動したときに続きから始められます。

## テスト

偽の ComfyUI と偽の LLM で動かします (`APPDATA` を一時フォルダに差し替えるので、実際の設定には触れません)。

```powershell
python tests\test_engine.py   # 量産の中心部分
python tests\ui_smoke.py      # 画面を回して、途中と終わったときの画面を PNG に撮る
python tests\test_story.py    # 物語のデータ (本物の短い mp4 を作って最後のコマなどを確かめる)
python tests\story_smoke.py   # 物語の画面 (シーン 2 つを作ってつなぐ)
python tests\test_send.py     # J-Rate・PromptWordCrafter からの「PrismLab に送る」(受ける側。別のプロセスから送るものも)
python tests\test_batch.py    # 物語のバッチと待ち行列 (量産ラインとの取り合い・一時停止・続きから)
python tests\test_hover_video.py  # 結果の「乗せると拡大」の動画再生
```

物語のコマを読むのに OpenCV (`opencv-python`) を使います (`pip install -r requirements.txt`)。

## 設定の保存先

`%APPDATA%\PrismLab\` (レシピ `recipes.json`、台 `machines.txt`、量産の状態 `line_run.json`、生成の記録 `comfy_history.txt`、窓の位置、最近開いた物語 `stories.txt`、物語のバッチの前の設定 `story_batch.json` と待ち行列 `story_batch_queue.json`、元画像などを選んだフォルダ `story_pick_folder.txt`)。共有するものは `%APPDATA%\GenCommon\`。物語そのものは物語のフォルダの `story.json`。

## 物語

シーンを横に並べた絵コンテで、1 シーンずつ作ってつなぎます。

1. **新しい物語...** で名前とフォルダを決めます (前に作ったものは「開く...」か上の欄から)。
2. シーンの **元画像** を決めます。シーンのあいだのつなぎを押すと **⟶ 続き** (前のシーンで採用した動画の最後のコマ) と **┃ シーンチェンジ** (手元の画像 / 前のシーンのコマ / T2I で作る) が切り替わります。顔などの **リファレンス画像** も、元画像とは別にシーンごとに決められます (ワークフローに、タイトルに「face」「reference」「顔」「参照」などを含む LoadImage があるときだけ)。
3. **プロンプト** は欄が 2 つです。上の **元のプロンプト** に自分の文を書きます (読み取る・盛るでは書き換わりません)。下の **盛ったあとのプロンプト (送る文)** には「読み取る」で元画像の説明が入り、「↓ 元の文を足す」で元の文を足し、「差し込み...」でセリフなどを足し、「盛る」で盛ります。送るのは下の欄の文です (空なら元のプロンプト)。**元に戻す / Ctrl+Z** で、読み取る・盛るの結果も 1 つずつ戻せます。送るプロンプトの移り変わりは **履歴...** でいつでも見て戻せます (閉じても残ります)。
4. ワークフローと候補の数を決めて **候補を作る**。選んで **採用して次へ** で次のシーンへ進みます。要らない候補は **Del** (または右クリックの「削除 (ごみ箱へ)」) でファイルごとごみ箱へ送れます (Ctrl / Shift で複数。複数のときだけ確かめます)。候補ごとに、作ったときの元のプロンプトと盛ったあとのプロンプトが残り (指を置くと出ます)、右クリックの **このときのプロンプトに戻す** で両方の欄に戻して、途中から直して作り直せます。
5. **▶ 通して再生** で、採用した動画を続けて再生します。採用した動画は物語のフォルダの `採用\01_名前.mp4` に番号順で揃います (動画編集ソフトに渡す)。
