# PrismLab

フォルダの画像から、読み取り → 盛る → ComfyUI の生成を、ステップをつないだ「量産ライン」で夜のあいだ回す PySide6 製のアプリです。ComfyUI は 3 台まで振り分けます。出来たものを見る・評価するのは J-Rate です。

```
入口 (フォルダ・★の絞り込み) → 読み取り → 盛る → 生成 (I2V など) → … → 出力フォルダ → J-Rate
```

決まりごとは [docs/spec.md](docs/spec.md) にあります。生成は J-Rate の `docs\generation-standard.md` に合わせ、生成・読み取り・盛るの部品は隣の `..\GenCommon\gencommon` を使います。

## セットアップと起動

```powershell
pip install -r requirements.txt
```

`run_app.bat` をダブルクリックするか、このフォルダで `python main.py` を実行します。すでに起動しているときは、起動中のウィンドウを手前に出します。

接続先・ワークフロー・ベースプロンプト・エンハンサー・読み取りプリセット・LLM の接続は、J-Rate・PromptWordCrafter・ImageMimicArt と共有します (`%APPDATA%\GenCommon\`)。

### EXE を作る

ImageMimicArt と同じく、PyInstaller で 1 つの EXE にします (隣の `..\GenCommon` も取り込みます)。

```powershell
python -m PyInstaller PrismLab.spec --noconfirm   # → dist\PrismLab.exe
```

- アイコンは `assets\icon.ico`。アプリのアイコン (`prismlab.main.make_icon`) を変えたら `python tools\make_ico.py` で作り直します。
- GenCommon を直したときも、EXE を作り直します (作った時点の GenCommon が中に入るため)。
- 1 ファイルの EXE なので、起動すると EXE のプロセスが 2 つ (起動役と本体) 見えます。

## 使い方 (量産ライン)

1. **台の設定...**: 量産で使う ComfyUI を 3 台まで選びます (登録してある接続先から)。台の札の **使う** のチェックを外すと、その台を一時的に休ませます (動いている件は最後まで作り、新しい件は送りません)。
2. 上の札で**レシピ**を選びます。初めは「★から動画」「実写クローン」「クローン → 動画」があります。右クリックで名前を変える・複製・並べ替え・削除、「＋ レシピ」で足せます。
   レシピが増えたら、右クリックの **まとまり ▸**「新しいまとまり...」で分けると、札の上にまとまりのタブ (例: PWC 6 / IE 3 / その他 2) が出て、選んだまとまりの札だけが並びます。タブの右クリックで名前を変える・並べ替え・まとまりを解く、ができます。
3. **入口**のステップをクリックしてフォルダを選び、★の絞り込みを決めます (J-Rate で付けた★を読みます)。★をこれから付けるときは、入口の「J-Rate で★を付ける」で J-Rate を開き、付け終わったら PrismLab に戻ります。戻ったときに★を読み直して、対象の枚数と★の内訳を描き直します。
   入口の上の **[テキスト]** に切り替えると、フォルダの .txt を 1 つずつ元の文にして T2I で量産します (最初の生成は T2I / T2V に)。**回数**はどの入口でも使え、同じ元を何回通すかを決めます。
   入口の上の **[1 枚]** に切り替えると、フォルダのかわりに 1 枚の画像から始めます (クリックかドラッグで選ぶ)。**回数**ぶん同じ画像を通すので、差し込み・盛るで 1 本ずつ違うものが出来ます。
4. **ステップ**をクリックして、そのステップの設定 (読み取りプリセット / エンハンサー / 足す文 / 差し込みのフォルダ / ワークフロー・長さ) を決めます。**追加テキスト**は入力した文を、**差し込み**はフォルダの .txt を 1 枚ごとに順に、プロンプトに足します。「盛る」より前に置くと一緒に盛り、あとに置くとそのまま付けます。設定の窓で、それまでの文の後ろ (既定) か前のどちらに足すかと、札に出す名前 (例: セリフ) を決められます。「＋ ステップ」で末尾に足し、ステップのあいだの **→** (乗せると「＋」) を押すとそこに挿入します。ステップのあいだの矢印には、そこを流れるものを色の線で描きます (上から 画像・動画 (動画は太い線。色は生成の種類の色) / 文字 / メモ (二重線) / 入れる画像 (リファレンスなど。サーモン色))。● はそのステップで作った・変えたもの、赤い ✕ は使われずに捨てられるもの (T2I に流れてきた画像、どの生成にも送られない文字)、灰色の ✕ は使い終わって消えたもの (生成に送った文字など) です。矢印にマウスを乗せると、流れるものとわけを説明します。ステップの下の端の **◀ ▶** で左右に動かせます。追加テキスト・差し込み・置き換えの札の見出しから処理バーの上までにマウスを乗せると、全文 (差し込みは次に使う .txt の中身) と**日本語訳**を小窓で出します (訳は「盛る」と同じ LLM。見るだけで文は変わりません。同じ文は 1 回だけ訳し、日本語だけの文は訳しません)。右クリックで設定・種類を変える・左/右に挿入・複製・バイパス・並べ替え・削除ができます。右クリックの **コピー** (「ここから右をまとめてコピー」も) で覚えたステップは、ほかのレシピでも右クリックの「左/右に貼り付け」や → の挿入のメニューで貼り付けられます。ほかに、**英語に** (いまのプロンプトの日本語などを LLM で英語に訳す。サーバー・モデルはエンハンサーと同じ。英語だけの文は送らず、同じ文は 1 回だけ訳す)、**置き換え** (「元 => 先」で語を置き換える・消す)、**増やす** (そこから先を N 本に分ける。読み取りは 1 回で、盛る・差し込みは 1 本ずつ変わる)、**★を待つ** (J-Rate で★を付けたものだけ先へ。「★を読み直す」「★待ちを終える...」)、**最後のコマ** (動画の最後のコマを画像にして次へ)、**画像 (1 枚)**・**画像 (フォルダ)** (決めた 1 枚かフォルダの画像 (1 件ごとに名前順かランダムに 1 枚ずつ) を、設定の **入れる先** に入れる。**流れている画像** なら差し替え (文はそのまま残るので、テキストの入口でも「文 + この画像」で I2I・I2V ができる)。**リファレンス** (タイトルに face / reference / 顔 など)・**ラストフレーム** (タイトルに last / end / ラスト など)・**ラベル** (タイトルがラベルと同じ) なら、このあとの生成のその画像の入口に入れ、生成を通っても入れる先が同じ次の画像のステップまで残る。画像の入口は LoadImage のほか、画像の名前を持つノード (カスタムノードの読み込みなど) も入る。＋ステップで選ぶと窓を出さずに画像なしで足すので、あとで札に画像 1 枚かフォルダ 1 つをドラッグ＆ドロップする (クリックして選んでもよい)) のステップがあります。追加テキストに `{red|blue}` と書くと、1 件ごとにどれかを選びます (ワイルドカード)。ステップ右上の **↷** はバイパスのスイッチで、入れるとそのステップを飛ばします。どのステップにも出て、それがないと動かないあとのステップ (読み取りに対する盛る など) は一緒にバイパスになり、どれかを切ると一緒に戻ります (生成が 1 つもなくなる・テキストの入口で画像がなくなるときは入りません)。
5. 出力の行の **元の★を引き継ぐ** (既定はオン) で、元の★を出来たファイルに付けます (1 件が終わった時点の★。更新日時は変えません)。
6. 量産の前に試すときは **▶ 1 枚で試す**。入口のサムネールをクリックするか、画像を入口にドラッグして 1 枚を選びます (選ばなければ先頭)。出力は `出力フォルダ\試作` に入り、右の欄に読み取った文・盛った文が出ます。結果を選ぶと、ふだんの量産でもその元と文が見られます。
7. **▶ 開始**。出来たものは下の「結果」に新しい順に並びます。「J-Rate で開く」で出力フォルダを J-Rate に渡します。
8. **待ち行列**: 開始はいつでも押せます。押したときのレシピの中身を写すので、そのあとでレシピを直しても、動いている量産・入れた量産は変わりません。量産が動いているときはボタンが **＋ 待ち行列に入れる** になり、前の量産の送る件がなくなったら (★待ちだけになったときも) 次を始めます。**1 枚で試す** は並ばずに、量産中でもすぐ動きます。台の札の下の **量産** の札に、動いているもの (▶)・待っているもの (⏳)・終わったもの (✓) が並びます。札を押すとその進み具合と結果を出し、レシピの札を押すとレシピに戻ります。右クリックで順番を変える・待ち行列から外す・中止・一覧から外す。

- ステップの色は、今のワークフローの色分けと同じです (T2I 青・I2I 緑・I2I CN 紫・T2V 橙・I2V 赤紫)。LLM のステップ (読み取り・盛る) は薄紫です。
- 出力は `(入口のフォルダ)\(レシピ名)\(元の名前)_video.mp4` など (出力フォルダは変えられます)。つないだステップでは `photo_cn_video.mp4` のように続けて付きます。
- 台に繋がらなくなったら、残りはほかの台に回し、戻ったらまた回します。
- 閉じるときに「残して閉じる」を選ぶと、次に起動したときに続きから始められます (待ち行列も残ります)。

## 物語

シーンを横に並べた絵コンテで、1 シーンずつ作ってつなぎます。

1. **新しい物語...** で名前とフォルダを決めます (前に作ったものは「開く...」か上の欄から)。
2. シーンの **元画像** を決めます。シーンのあいだのつなぎを押すと **⟶ 続き** (前のシーンで採用した動画の最後のコマ) と **┃ シーンチェンジ** (手元の画像 / 前のシーンのコマ / T2I で作る) が切り替わります。顔などの **リファレンス画像** も、元画像とは別にシーンごとに決められます (ワークフローに、タイトルに「face」「reference」「顔」「参照」などを含む LoadImage があるときだけ)。
3. **プロンプト** は欄が 2 つです。上の **元のプロンプト** に自分の文を書きます (読み取る・盛るでは書き換わりません)。下の **盛ったあとのプロンプト (送る文)** には「読み取る」で元画像の説明が入り、「↓ 元の文を足す」で元の文を足し、「差し込み...」でセリフなどを足し、「盛る」で盛ります。送るのは下の欄の文です (空なら元のプロンプト)。**元に戻す / Ctrl+Z** で、読み取る・盛るの結果も 1 つずつ戻せます。送るプロンプトの移り変わりは **履歴...** でいつでも見て戻せます (閉じても残ります)。
4. ワークフローと候補の数を決めて **候補を作る**。選んで **採用して次へ** で次のシーンへ進みます。候補を作っているあいだも、別のシーンを選んで候補を作れます (「続き」のシーンだけは、前のシーンが作り終わるのを待ちます)。要らない候補は **Del** (または右クリックの「削除 (ごみ箱へ)」) でファイルごとごみ箱へ送れます (Ctrl / Shift で複数。複数のときだけ確かめます)。候補ごとに、作ったときの元のプロンプトと盛ったあとのプロンプトが残り (指を置くと出ます)、右クリックの **このときのプロンプトに戻す** で両方の欄に戻して、途中から直して作り直せます。
5. **▶ 通して再生** で、採用した動画を続けて再生します。採用した動画は物語のフォルダの `採用\01_名前.mp4` に番号順で揃います (動画編集ソフトに渡す)。
